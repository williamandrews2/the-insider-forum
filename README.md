# 🕶️The Insider Forum

## 👁️ Overview
This is a project from [this lesson](https://www.theodinproject.com/lessons/node-path-nodejs-members-only#project-solution) in The Odin Project. This is an exclusive forum where members can write anonymous posts. Inside the forum, members can see who the author of a post is, but outside, they can only see the story and wonder who wrote it. A live render of the app can be found [here](https://the-insider-forum.onrender.com)!

## 🎓 Learning Outcome
I have chosen to take a slightly different approach in the name (as opposed to Members Only); however, the goals and learning outcome of the project remain the same. Started the project on February 4, 2026.
